# For Riri

A small birthday experience built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personal media

The original AppDeploy project references private media files under `public/resources/`:

- `riri-01.jpg` through `riri-08.jpg`
- `riri-video.mp4`
- `riri-video-cover.jpg`
- `beautiful-by-phyno.mp3`

Those media files were not part of the source export and are intentionally not included in this repository. Add them under `public/resources/` to restore the original gallery and soundtrack.
